# Rules - Cleanique Academy

## Aturan Desain & Struktur Interface

1. **Dilarang Menggunakan Icon Sistem / Emoji**:
   - Tidak boleh menggunakan emoji atau ikon sistem OS (seperti 🏆, 🛠️, 🚚, 🧺, 🧪, 🏢, 📦, 🏠, 👤, 💼, 📚, 🔬, 💡, 📜, 🎁, 📍, 📅, 👥, 💰, ⏱️, ⚙️, 🔥, ⚡, dll.).
   - Gunakan tipografi modern, badge bersih, atau layout kartu tanpa emoji.

2. **Penggunaan Icon Sosial Media Resmi**:
   - Setiap elemen media sosial (WhatsApp, Instagram, Facebook, YouTube, TikTok) wajib menggunakan ikon SVG resmi dari platform tersebut secara langsung.

3. **Single Page Landing Page Tanpa Menu Navigasi Bertumpuk**:
   - Halaman utama / landing page pada `index` tidak memiliki menu navigasi tautan bertumpuk (seperti Beranda, Program, Benefit, Testimoni, Kontak, dll.).
   - Header hanya terdiri dari **Logo Cleanique Academy** di sisi kiri dan **Tombol CTA Utama (WhatsApp)** di sisi kanan.
